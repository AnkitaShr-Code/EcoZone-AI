08

Gemini on Vertex AI does the proposing and the writing; we call it through the google-genai SDK from a small loop in plain asyncio rather than an agent framework, so every step is testable. The engine is Python with shapely, geopandas and pvlib, the front end is React with deck.gl and MapLibre, and it all runs on Cloud Run built by Cloud Build. Earth Engine and Landsat appear only in the heat check, never in a score.
