### Satellite data

- **Datasets:** `LANDSAT/LC08/C02/T1_L2`, `LANDSAT/LC09/C02/T1_L2`, band ST_B10 (surface temperature)
- **Window 2026:** 2026-03-01 to 2026-05-31; scenes: `LANDSAT/LC08/C02/T1_L2` 5, `LANDSAT/LC09/C02/T1_L2` 5
- **Years used:** 2026
- **Scenes used:** 10 scenes (minimum 5: met); per-pixel median over the window
- **Screening:** scenes over 30% cloud cover excluded; cloud, cloud shadow, dilated cloud and cirrus pixels masked; pixels the product's own per-pixel uncertainty band marks as unreliable masked (the limit is our own choice, set before the run and recorded in the data file's provenance)
- **Aggregation:** median over each block at 30 m (native thermal resolution 100 m)
- **Blocks:** 65 of 65 blocks had a valid pixel (0 dropped); valid pixels per block (coverage-weighted): minimum 3, median 13, maximum 178
- **Fetched:** 2026-10-18 from Earth Engine project `ecozone-ai-2026`

### Caveats

- Surface temperature is not the air temperature people feel.
- The heat index shares inputs with what drives surface temperature (paving, green cover, built volume, roof reflectance), so agreement shows that the index ranks blocks sensibly, not that its weights are right.
- Landsat sees the top of a shade structure, not the shaded ground under it, so satellite data can never confirm that shade structures work.
- Landsat thermal bands are collected at 100 m and resampled to 30 m; a block of only a few pixels is a mixed measurement, and each block's valid pixel count is recorded.
- Each scene is one overpass in the late morning, not the afternoon peak.
- The test half is a small sample; read the block count and the p-value with it, not the correlation alone.

## How the search was driven

`evals/evalkit/adapter.py` hands the agents' search loop the engine's own public API (`summary`, `layer`, `single_site`, `rescore`, `greedy_baseline`). `rescore` is never cached. Greedy for each case and every offered site's single-site result are computed once in this process with the same engine functions and reused by the search runs, to save wall time. Search runs use a long time limit so the wall clock cannot change what a run does.
